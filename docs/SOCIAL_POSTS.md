## LinkedIn

I wanted to improve my typing speed, so I built typedef: a lightweight typing application that runs in the terminal.

It's built with Rust, Ratatui and Crossterm. Practice works offline, and typing history stays on your machine.

Some of the technical details:

- Nine practice modes, including timed tests, endless sessions, weak-key drills, custom text and code practice with Tab indentation.
- Live WPM, raw speed and accuracy, plus personal records and per-key error heatmaps.
- Cached word wrapping that adapts to terminal width without changing the source text.
- JSON profiles with atomic saves and an exclusive process lock.
- Native releases for macOS, Linux and Windows, with CI across all three. macOS/Linux users can install through curl or Homebrew and launch it with `tpdf`.

There are also 28 themes, daily streaks and repeating badge tiers to keep practice interesting.

Feel free to try it out! I'd appreciate feedback on the typing experience and terminal compatibility. If you find it useful, give it a star on GitHub. Contributions to the Rust codebase are welcome too.

Try it: https://typedef-tui.vercel.app
Source: https://github.com/rawatpriyansh17/typedef
