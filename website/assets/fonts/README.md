# Website fonts

- **Orbitron**: headings and wordmark. [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/orbitron), SIL Open Font License in `Orbitron-OFL.txt`.
- **Geist**: body text and controls. [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/geist), SIL Open Font License in `Geist-OFL.txt`.

The Latin WOFF2 subsets are self-hosted; the website makes no requests to Google Fonts at runtime.
