# Website fonts

- **Orbitron**: headings and wordmark. [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/orbitron), SIL Open Font License in `Orbitron-OFL.txt`.
- **Oxanium**: body text, navigation, controls and commands. [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/oxanium), SIL Open Font License in `Oxanium-OFL.txt`.

Both Latin WOFF2 subsets are self-hosted. The website makes no requests to Google Fonts at runtime. App screenshots preserve the terminal's own typography.
